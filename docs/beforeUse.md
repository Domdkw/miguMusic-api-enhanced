# 已知问题

!> 请不要使用不信任的后端服务进行登陆操作，避免盗号风险。请使用客户端SDK。日志可以直接打印出账号密码。

- 国外IP可能无法获取到音乐播放地址，需要在大陆地区使用。
- 绕过缓存，可以使用`?_t=`传入时间戳。
- [用户名密码登录接口](api/passport.md#2.账号密码登录)会暴露账号密码，存在安全风险。已在高版本中移除。
- 若接口未标注**请求方法**，默认为 `GET`。
